## Embedded session, storage and transport (pi-durable-jsrt)

Architecture: `@earendil-works/pi-durable` (root, /storage/{memory,jsonl,jsonl/node,sqlite,sqlite/node,sqlite/cloudflare,indexeddb}, package.json) and the internal session/transaction/ids/types/documents/entries/tasks modules are plain-JS glue over one native service: the stock gate's Hub (task_stock_bridge.rs + examples/support/*) hosted in-process by src/dispatch/transport.rs. There is no second Session or memory implementation, so the stock process gate and the embedded package exercise the same Rust. MemoryStorage (and subclasses) are Hub memory stores shared directly with native Sessions/Harnesses; openNodeSqliteStorage returns an upstream SqliteStorage instance; SqliteStorage.open(driver) and JsonlStorage.open(dir, env) run native storages over the caller's JS driver/filesystem objects, with driver calls starting on the JS thread in call order.

Round trips: cost is cross-thread handoff, not CPU. Host round trips per commit 22.7 -> 15.0 (memory.call runs to completion on the JS thread with adopt(seq) before settling, as upstream; opt-in SessionOptions::clock_reader reads clock+retention once per touch/sweep/arm step; Session::touch matches upstream #touchDocument). The 600-commit retention case takes 1.4 s of its 5 s deadline (was 2.4–3.0 s).

Bugs fixed with regressions: transport context race (deferred callbacks read context after a same-batch context.drop; fixed in embedded and stock transports; session_embedded::watch_delivery_keeps_the_commit_context); nested-delivery deadlock (a sync request during frame dispatch waited on a sync callback queued behind it; oldest-first shared backlog; ~1 hang per 35–40 runs -> 0 in 100); kernel touch parity; Boa inline-cache `arr.length = n` truncation and arrow-retained `this` (found here, fixed in vendor Boa). The vitest shim aborts the test signal on timeout, as vitest does.

Evidence: porting/durable/mappings/embedded-session.json 700/700 case-runs (8 session files, memory, jsonl, sqlite-storage/-facade/-migrations/-cloudflare, both modes; adoption with --features stock-test-probes); storage-runtime-boundary n/a (checks upstream source layout), with session_embedded::portable_entry_modules_import_no_node_builtins checking the glue; all 66 top-level durable test files pass embedded in both modes; stock session gate green throughout.

Remaining limits: every host interaction is a thread handoff (~0.1–0.2 ms, more under load), so deadline-tight upstream cases can time out above load average ~200.
