## Embedded code mode and tools

`@earendil-works/pi-codemode` is embedded too, because its upstream VM is QuickJS-wasm, which Boa cannot run. js/pi-codemode/* sits over the native pi-codemode crate (src/dispatch/codemode{,/sdk,/live}.rs): every runtime export is native and each VM is pi-codemode's Boa VM on its own thread. `CodemodeSandbox` (deterministic `start` keeping every UTF-16 unit; `execute` with live JS tools/globals, store, abort, close, register/unregister, acquireWorker/onWorkerStarted), `InlineCodemodeSandbox` (interrupt budget, default 100000), `RemoteCodemodeSandbox`/`serveCodemodeRemote` over the caller's JS remote, native declarations and source parsing; `loadQuickJSWasm` resolves to an inert stand-in, and a rejecting `wasm` promise still fails executions as upstream. Durable code mode, tool search and the built-in tool task run in the shared in-process Hub; js/codemode, js/tool-search and js/internal/src/durable/{codemode,harness/tool}.js port the stock adapters onto the in-process transport.

With n/a: sandbox 143/153, deterministic 28/30, portable 5/7, worker-lifetime 8/14.

Boa patches (vendor/boa_engine/PATCH.md, regressions in crates/pi-jsrt/tests/boa_patches.rs): linear string search from a position (split/replaceAll/indexOf/includes; a 6 MiB output case 14 s -> 1.7 s); catchable stack overflow (`RangeError: Maximum call stack size exceeded`, value stack truncated on mid-unwind catch); V8 wording for cyclic JSON.stringify. Deterministic Math.random ports QuickJS's xorshift64* (state seed+1, one draw at context creation, upstream's exact values); pi-codemode determinism version 5. pi-jsrt `process.env` is live; setting TZ changes the runtime timezone.

The 20 n/a: fingerprint format (2: durable code mode refuses to resume across a VM fingerprint change, so in-flight runs never move between engines, as upstream won't between QuickJS versions; completed journal/result/store data is plain JSON and interchanges); interrupt-budget unit (3: QuickJS counts polls, pi-codemode counts loop iterations and promise jobs); no Boa heap limit (1; only ArrayBuffer allocations are capped); custom raw-worker fixture scripts (8); Node Worker.prototype spies and process fixtures that run upstream source (6).
